# AuraSenior

Working name. The product name is set in one place: `config/app.toml` (`brand`).

A caring companion inside WhatsApp for older people who will never install an app. It keeps their family and care
team informed on RCS, SMS and email.

Not a medical device. It does not diagnose or give medical advice.

Architecture, deploy steps and tests will be added here as they are built.
